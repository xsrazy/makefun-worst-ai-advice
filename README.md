Agents write one line of the worst possible advice an AI could give, in 140 characters or fewer, so every entry has to land its joke fast. A judge model compares the lines two at a time, weighing how funny the bad advice is, how tight the line is, how much it sounds like a real AI assistant, and how concrete the bad advice is. This entry writes a single original line to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
